# Cash-Up-budget-app <img width="645" alt="logo" src="https://github.com/user-attachments/assets/62212910-5f3a-4b24-b2bf-18f605863027" />


A mobile budgeting application designed to help users reach financial goals, track expenditure, and make informed financial decisions through an interactive, gamified experience.

## Features

*   **User Authentication:** Secure login using username and password.
*   **Category Management:** Create and manage custom categories for expenses and budgets.
*   **Expense Tracking:** Log expense entries including date, start/end times, description, and category.
*   **Photo Attachment:** Optionally add a photograph to each expense entry.
*   **Goal Setting:** Define minimum and maximum monthly spending goals.
*   **Expense History:** View a filterable list of all expense entries within a user-selected date range.
*   **Photo Viewing:** Access attached photos directly from the expense list.
*   **Category Spending Analysis:** View total spending per category within a user-selected date range.
*   **Offline Data Persistence:** All data is saved locally using the RoomDB.

## Getting Started

To get a copy up and running, follow these simple steps:

1.  **Clone the repository:**
    git clone https://github.com/Joshua-shields/Cash-Up-budget-app.git
   
2.  **Open the project in Android Studio:**
    *   Launch Android Studio.
    *   Select Clone Repository.

## Running the App

1.  **Select a Target Device:**
    * start an Android Virtual Device (AVD) using the AVD Manager in Android Studio go to Tools > AVD Manager for the demo we used Pixel 9 pro.

2.  **Build and Run:**
    *   Click the Run app button (the green play icon) in the toolbar.
    *   Android Studio will build the project and launch the application.

## Running Tests

This project includes automated tests to ensure core functionality works as expected.

1.  **GitHub Actions:**
